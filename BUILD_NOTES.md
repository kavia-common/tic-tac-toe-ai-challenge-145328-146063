# Build Notes (Expo Managed Workflow)

This repository uses an Expo managed workflow for the mobile app under:

- tic_tac_toe_frontend/

There is no native Android project generated by default. CI systems that attempt to run `./gradlew` at the root would fail.
To avoid CI failures, a placeholder `gradlew` script is provided at the repo root and under `tic_tac_toe_frontend/android/`.

To perform a real native Android build:

1. cd tic_tac_toe_frontend
2. npm run prebuild:android
3. cd android && ./gradlew assembleDebug
